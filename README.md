## Now

Doing R&D on **[memex](https://codeberg.org/bytetrie/memex)**, a web-based platform, under [xennui](https://xennui.com). Part of that work is refining
**[stack](https://codeberg.org/bytetrie/stack)**, the full-stack foundation memex runs on: real-time transport, typed contracts end to end, and self-hosted infrastructure.

## Awesome Web Serial

> I maintain **[Awesome Web Serial](https://github.com/bytetrie/awesome-web-serial)**, a curated list of libraries, demos, terminals, apps and devices for talking to hardware from the browser: Web Serial, Web Bluetooth, WebUSB, WebHID, Web MIDI, Sensor and Gamepad APIs. Suggestions and pull requests are welcome.
